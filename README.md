## 📦 What's Inside This Package

This archive contains the full production-ready codebase for **Khushi Travels**:
* **Frontend:** React 19 + Tailwind CSS v4 + Lucide Icons + Canvas Confetti
* **Backend API:** Node.js + Express + JWT Authentication + BCrypt Password Hashing
* **Database:** SQLite Database (`better-sqlite3`) pre-seeded with vehicles, destinations, tour packages, reviews, and bookings
* **Notification Subsystem:** SMS Notification Engine (Customer Receipt, Admin Alert, Confirmation, Status Updates) + WhatsApp Bridge
* **Admin Management Console:** Complete booking management, driver assignment, vehicle fleet editor, package editor, and SMS audit logs

---

## 🚀 Quick Start (How to Run)

### 1. Extract and Install Dependencies
```bash
cd khushi-travels
npm install
```

### 2. Run Both Frontend and Backend Concurrently
```bash
npm run dev:all
```
* **Frontend Web App:** `http://localhost:3000`
* **Backend REST API:** `http://localhost:5001`

### 3. Run Production Build
```bash
npm run build
npm start
```
